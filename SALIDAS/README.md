# SALIDAS

Carpeta de destino para todos los resultados generados por los scripts del
proyecto: grabaciones `.npy`, gráficas exportadas, y cualquier otro archivo
de salida de una corrida.

No se versiona el contenido de esta carpeta (ver `.gitignore` en la raíz) —
solo este `README.md` como marcador, para que la carpeta siempre exista y
todos los scripts tengan un destino consistente.

Si agregas un script nuevo que genere resultados, que los guarde aquí en
vez de la raíz del proyecto o de `Avances/`.
